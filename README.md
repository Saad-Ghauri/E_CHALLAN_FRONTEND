# Smart Challan — Frontend (Next.js)

```
copy .env.local.example .env.local   # API URL, default http://localhost:8000/api
npm run dev
```

Structure: `app/` routes · `components/shared/` reusable UI (DataTable, FormDialog, StatusBadge…) ·
`components/<feature>/` feature UI · `hooks/` data & form hooks · `lib/` API client, types, formatting, nav config.
